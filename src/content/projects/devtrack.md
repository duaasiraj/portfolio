## Overview

DevTrack is a full-stack bug tracking and project management platform designed to help teams manage software issues, projects, users, and collaboration workflows.

The application provides role-based access control, issue management, project organization, and backend-driven analytics displayed through frontend dashboards.

My contributions focused on frontend integration, connecting backend APIs with the React interface, and extracting backend statistics to power visualization components and project analytics.

## Highlights

* Integrated frontend workflows with REST APIs built using Node.js and Express
* Developed UI components for issue tracking and project management flows
* Connected backend analytics data to frontend visualization dashboards
* Worked with authentication flows and role-based application states
* Collaborated on full-stack architecture using PostgreSQL and React

## Stack

React, Node.js, Express.js, PostgreSQL, REST APIs, JWT Authentication
