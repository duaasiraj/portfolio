## Overview

Dungeon Escape is a 2D tile-based dungeon exploration game built in C++ using Raylib. The project focuses on applying object-oriented design principles to game development, including entity management, combat systems, animations, and interactive gameplay mechanics.

I contributed to game planning and architecture while implementing enemy systems, sprite handling, animations, and gameplay interactions. The project explores how larger interactive systems can be structured using modular C++ classes and reusable components.

## Highlights

* Designed gameplay architecture using object-oriented programming principles
* Implemented enemy entities with movement, chasing, and attack behaviors
* Developed sprite handling and animation systems for game characters
* Integrated player movement, combat mechanics, collectibles, and scoring systems
* Worked with Raylib for rendering, input handling, and game loop management
* Structured game components into reusable C++ classes
