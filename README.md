# Duaa Siraj — Portfolio

[Live Demo](link)

Personal portfolio website showcasing my work across AI, machine learning, systems programming, and software engineering.

Built with Astro and TypeScript, focusing on performance, minimal design, and documenting the engineering behind each project.

## Tech Stack

- Astro
- TypeScript
- JavaScript
- HTML/CSS

## Features

- Project showcase with technical write-ups
- Experience and research timeline
- Responsive minimal UI
- Content-driven architecture using Astro Content Collections

## Running Locally

```bash
git clone https://github.com/duaasiraj/portfolio.git
cd portfolio
npm install
npm run dev
```

## Deployment

Built as a static Astro site and deployed online.
